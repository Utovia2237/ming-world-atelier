# 溟 · 世界工坊

在线使用：[打开世界工坊](https://utovia2237.github.io/ming-world-atelier/)。离线时也可双击 **启动世界工坊.cmd** 或打开 **index.html**。建议使用新版 Edge、Chrome 或 Firefox。工具无需后端、API 密钥或付费服务。

本项目由作者与 OpenAI Codex 协助构建、测试和部署。地形算法、参数约束与内容设定由项目作者负责；Codex 协助完成代码实现和自动化验证。

## 功能

- 正圆地图、中央连通内海、连续环状大陆。圆周内侧始终为陆地；不生成河流、湖泊或其他内陆水网。
- 海洋面积 10%～20%，以圆内实际连通水域面积校准；地图圆半径扩大到接近正方形内切圆，预览和导出像素分辨率保持不变。可调海岸破碎度、拉伸状海岸权重、中央岛屿面积（0.1%～1%）、山地密度、山系平均距离与距离方差、近海群岛和地形起伏。山系分为网状脊群、链状主脉和流线褶皱三类，占比滑块联动并始终合计 100%。
- 4 套高度配色。每个颜色节点关联海拔，支持渐变或分层设色。
- 晕渲支持两种光源：沿固定半径圆周移动并始终面向地图中心，或固定在地图中心正上方并调整 10%～40% 的高度。还可开关等高线（200 / 400 / 800 米）、海底分层、海岸描边、纸面肌理、圆周刻度、八向轴线、半径圆线、图例与边缘淡化。
- 原生重算的 1536、2880、4096 像素正方形 PNG 导出，可选圆外透明背景。
- 可导入/导出完整项目 JSON、导出 16 位灰度 PNG 高度图；同版本、种子、分辨率与参数可复现。
- 预览支持缩放、平移、双击复位及全屏。

## 使用方法

1. 点击随机种子探索地貌，或输入任意种子后按 Enter。
2. 调整地形、设色和图层参数，最后点击「生成世界」统一应用。山系占比滑块联动，合计始终为 100%；它们表示区域权重，不保证像素面积与数字完全相等。地图中心固定生成小型中央岛屿，并在岛屿边缘到最近大陆海岸的最短方向生成岛链。
3. 在「图层」选择环绕光源并拖动方位盘（0° 为北，90° 为东），或选择中心上方光源并调整高度。光照只改变明暗，不改变高度场或海陆边界。
4. 在「导出」选择 2880（与第一张参考图像素尺寸相同）或 4096 像素后导出。高清图按当前参数与输出尺寸重新计算，不放大预览；运算期间设置会暂时锁定。

## 实现说明

种子化 Simplex 噪声 → 域扭曲的多尺度大陆场 → 中央四连通海域洪泛与面积二分校准 → 优先队列扩展至目标水域像素数 → 内陆不连通洼地填为陆地 → 海岸距离变换 → 三类山系与脊状高度 → 分层设色和可调光源的双尺度晕渲。

网状脊群保留交织的脊状分形；链状主脉以低频弯曲的主山脊连接散开的支脉；流线褶皱采用沿环向延展的各向异性脊状分形。种子控制成片分区，三类高度在交界与重叠处按连续权重混合，避免硬接缝。海岸拉伸参数增加沿方向延展的褶皱扰动。环绕光源在西北默认方位到中心的固定距离（约 0.8 个归一化半径）上移动；中心上方模式根据可调高度计算入射光。

圆周内最后 2.6% 的半径始终约束为陆地，并裁切在精确圆内。大陆外缘因此每个方向都触及圆框。海洋面积控制整个圆内的连通水面，误差不超过半个圆内像素；界面显示实测值。更换分辨率后会重新采样海岸线，细小岛屿和通道可能略有变化。

视觉目标是参考图的环形构图、曲折内海岸、近海群岛和山脊晕渲。程序化生成与图像模型不是逐像素复刻。地形高度为相对高度，不是现实测量数据；本工具不生成地名、政治边界或设定特有的灾害符号。

## 高度图格式

PNG 使用 16 位无符号灰度值：高度（米）= 灰度 / 65535 × 16000 − 8000；圆外为 0。文件保留 16 位精度，浏览器预览可能会以 8 位显示。

## 样图与验证

「中央岛链检查-1280.png」用于核验当前中央岛屿和岛链的海岸形态。「示例地图-2880.png」和「山系样式对比.png」为较早版本的参考样图；旧项目导入时会按当前滑块边界校准。预览为 1280 × 1280，导出的像素尺寸独立于预览缩放。旧版 1.0 项目导入后自动设为仅原有山系。

已自动验证不同种子和极端参数下的全周接陆、正圆裁切、中央海域全部连通、海洋占比、种子复现、中央岛屿与最近海岸岛链、三种山系与连续过渡、光源方向、等高线与配色开关，以及 16 位 PNG 的像素值和 CRC。界面逻辑通过 jsdom 和真实后台线程验证，涵盖方位盘、刻度装饰、设置联动、旧项目迁移、项目往返与导出锁定。

自动化验证包括地形约束与基于 jsdom 的界面测试；真实浏览器的布局与交互检查应作为发布后的补充验证。

开发验证需要 Node.js 22.2 或更新版本。在本目录执行「npm install」安装仅用于测试的依赖，然后运行：

- 「npm test」：地形约束、格式与界面逻辑测试。
- 「npm run test:hires」：4096 原生渲染、透明 PNG 和 16 位高度图检查。
- 「npm run sample」：重新生成 2880 样图与示例项目。
- 「npm run sample:variants」：重新生成三种山系与混合山系的对比图。

默认样图的渲染数据记录在 tests/last-render.json。运行高清专项测试后会生成 tests/high-resolution.json；耗时取决于电脑性能。日常打开工具不需要 Node.js 或这些测试依赖。

## 项目文件

- index.html：工具界面。
- styles.css：响应式布局。
- controls.css：山系占比和可移动光源方位盘的样式。
- terrain.js：地形、渲染和 PNG 引擎，同时支持浏览器与 Node.js。
- app.js：用户界面和后台运算线程。
- tests/：地形约束、界面逻辑与高清 PNG 自动化测试。
- package.json：开发测试命令与依赖；不参与浏览器运行。

## 数据保存与隐私

工具不提供云端保存或跨浏览器同步。地图计算、项目导入和文件导出均在使用者的浏览器中完成；参数与地图不会上传到 GitHub 仓库，也不会成为其他使用者的默认设置。

自动记忆仅使用当前浏览器中本网站的 `localStorage`，由浏览器按来源隔离。下次在同一浏览器打开时会恢复本机缓存的参数；其他设备、浏览器或新的浏览器用户配置会从默认设置开始。同一设备多人共用同一个浏览器用户配置时，可能共用该浏览器缓存，可点击「重置」恢复默认设置。离线版本继续保留原有的参数记忆逻辑。

**浏览器缓存不是可靠备份，本站不会在云端保留你的项目或生成结果。请自行点击「保存项目」导出 JSON，并导出满意的 PNG 地图或高度图。** 清除网站数据、使用无痕窗口或更换设备可能丢失本机缓存；之后可导入项目 JSON 继续编辑。

不加载远程脚本、字体或素材。
