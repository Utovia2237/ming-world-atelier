# 溟 · 世界工坊

在线使用：[打开世界工坊](https://utovia2237.github.io/ming-world-atelier/)。离线使用时，下载并解压整个仓库，打开 **index.html**，保留同目录下的 CSS、JavaScript 和 `assets/` 文件夹。建议使用新版 Edge、Chrome 或 Firefox。工具无需安装依赖，也不需要后端、API 密钥或付费服务。

本项目由作者与 OpenAI Codex 协助构建、测试和部署。地形算法、参数约束与内容设定由项目作者负责；Codex 协助完成代码实现和自动化验证。

## 功能

- 正圆地图、中央连通内海、连续环状大陆。圆周内侧始终为陆地；不生成河流、湖泊或其他内陆水网。
- 地形直径按 200 km 标定；界面比例尺按半径 2,000 km（全图直径 4,000 km）换算，随地图缩放更新，并固定在中央面板右下角、不随地图平移。
- 海洋面积 10%～20%，以圆内实际连通水域面积校准；地图圆半径扩大到接近正方形内切圆，预览和导出像素分辨率保持不变。可调海岸破碎度、拉伸状海岸权重、中央岛屿面积（0%～0.1%）、山地密度、山系平均距离与距离方差、近海群岛和地形起伏。山系分为网状脊群、链状主脉和流线褶皱三类，占比滑块联动并始终合计 100%。
- 左侧地形构造、中央地图预览、右侧地形风格的三栏界面。深色终端与浅色蓝图主题可切换，主题偏好仅保存在本机。
- 4 套高度配色支持连续渐变与分层设色；终端、蓝图两种预设锁定为极简等高线。高度色带始终展开，普通配色和等高线均可编辑高度节点颜色。
- 晕渲使用中心上方光源并可调整 10%～40% 高度。可开关等高线（200 / 400 / 600 / 800 米）、海底分层和圆周刻度。
- 原生重算的 1536、2880、4096 像素正方形 PNG 导出，圆外区域固定透明。
- 可导入/导出完整项目 JSON、导出 16 位灰度 PNG 高度图；同版本、种子、分辨率与参数可复现。
- 预览支持缩放、平移和双击复位；左侧地形参数点击「生成世界」后应用，右侧风格设置即时重绘当前地图。

## 使用方法

1. 手动输入种子后点击「生成世界」，或点击种子框旁的随机按钮，立即用新种子和当前左栏参数生成地图。
2. 调整左栏地形参数后点击「生成世界」应用。山系占比滑块联动，合计始终为 100%；地图中心可生成 0%～0.1% 的中央岛屿，近海群岛影响其海岸细节。
3. 在右栏调整设色、渲染、光源高度或图层，变化即时应用到当前地图。极简等高线描绘陆地与海底，不使用晕渲。
4. 点击顶部「导出地图」，选择 1536、2880 或 4096 像素，再导出 PNG、16 位高度图或项目 JSON。PNG 圆外区域始终透明；高清图按当前已应用地形与输出尺寸重新计算。右栏底部可导入项目。
5. 顶部深浅模式按钮仅切换界面，不修改地图参数或已生成图像。

## 实现说明

种子化 Simplex 噪声 → 域扭曲的多尺度大陆场 → 中央四连通海域洪泛与面积二分校准 → 优先队列扩展至目标水域像素数 → 内陆不连通洼地填为陆地 → 海岸距离变换 → 三类山系与脊状高度 → 分层设色和可调光源的双尺度晕渲。

网状脊群保留交织的脊状分形；链状主脉以低频弯曲的主山脊连接散开的支脉；流线褶皱采用沿环向延展的各向异性脊状分形。种子控制成片分区，三类高度在交界与重叠处按连续权重混合，避免硬接缝。海岸拉伸参数增加沿方向延展的褶皱扰动；晕渲由中心上方光源根据可调高度计算入射光。

圆周内最后 2.6% 的半径始终约束为陆地，并裁切在精确圆内。大陆外缘因此每个方向都触及圆框。海洋面积控制整个圆内的连通水面，误差不超过半个圆内像素；界面显示实测值。更换分辨率后会重新采样海岸线，细小岛屿和通道可能略有变化。

视觉目标是参考图的环形构图、曲折内海岸、近海群岛和山脊晕渲。程序化生成与图像模型不是逐像素复刻。地形高度为相对高度，不是现实测量数据；本工具不生成地名、政治边界或设定特有的灾害符号。

## 高度图格式

PNG 使用 16 位无符号灰度值：高度（米）= 灰度 / 65535 × 16000 − 8000；圆外为 0。文件保留 16 位精度，浏览器预览可能会以 8 位显示。

## 预览与项目兼容

预览为 1280 × 1280，导出的像素尺寸独立于预览缩放。仅接受当前格式版本的项目 JSON；不支持的旧版本会提示拒绝导入。

已自动验证不同种子和极端参数下的全周接陆、正圆裁切、中央海域全部连通、海洋占比、种子复现、中央岛屿、三种山系与连续过渡、等高线与配色开关，以及 16 位 PNG 的像素值和 CRC。界面逻辑通过 jsdom 和真实后台线程验证，涵盖刻度装饰、设置联动、旧格式拒绝、项目往返与导出锁定。

测试脚本、开发依赖和验收截图保留在作者本地，公开仓库只提供运行文件与使用说明。日常使用不需要 Node.js。

## 项目文件

- index.html：工具界面。
- styles.css：响应式布局。
- controls.css：光源高度等专用控件样式。
- terrain.js：地形、渲染和 PNG 引擎，同时支持浏览器与 Node.js。
- app.js：用户界面和后台运算线程。
- assets/MINGlogo.svg、assets/MINGlogo-light.svg：深浅界面使用的品牌图标。

## 数据保存与隐私

工具不提供云端保存或跨浏览器同步。地图计算、项目导入和文件导出均在使用者的浏览器中完成；参数与地图不会上传到 GitHub 仓库，也不会成为其他使用者的默认设置。

自动记忆仅使用当前浏览器中本网站的 `localStorage`，由浏览器按来源隔离。下次在同一浏览器打开时会恢复本机缓存的参数；其他设备、浏览器或新的浏览器用户配置会从默认设置开始。同一设备多人共用同一个浏览器用户配置时，可能共用该浏览器缓存，可点击「重置」恢复默认设置。离线版本继续保留原有的参数记忆逻辑。

**浏览器缓存不是可靠备份，本站不会在云端保留你的项目或生成结果。请自行点击「保存项目」导出 JSON，并导出满意的 PNG 地图或高度图。** 清除网站数据、使用无痕窗口或更换设备可能丢失本机缓存；之后可导入项目 JSON 继续编辑。

不加载远程脚本、字体或素材。
